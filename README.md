# SHITAGAKI

> **いつでもどこでも、ほんの下書きが本の下書きになる。**

SHITAGAKI（下書き）は、声や文章で「ほんのちょっとした下書き」を残し、
時間とともに「本の下書き」に育て、最終的に紙の本・電子書籍・音声として残せるサービスです。

## できること

- **電車の中で30秒話す** → 自動で文字起こし・タグ付け
- **寝る前に1分ボイスメモ** → エピソードカードに変換
- **カードを並べ替える** → 時系列・人物・場所が整理されていく
- **確認するだけで本ができる** → 紙 + 電子書籍 + 元の肉声データ

## 3ステップで本ができる

```
1. 残す      音声・テキスト・写真をサッと記録
2. 並べる    AIが整理したカードを本人が確認・並べ替え
3. 本になる   紙の本 / 電子書籍 / 音声データとして完成
```

## 特徴

| 既存の自分史サービス | SHITAGAKI |
|---|---|
| 一度きりの高額インタビュー | 日常の「ほんの下書き」の積み重ね |
| 業者が書く | 本人が話す・並べる・確認する |
| 本だけが成果物 | **本 + 元になった本人の肉声** |
| 3.5万円〜 | **低価格・小さく始められる** |

## 価格イメージ

- 小さく始める: 無料 or 月額数百円
- 本を生成: 200ページ・1,000円〜を目標

## 技術

SHITAGAKI は [progressive-life](https://github.com/bonsai/progressive-life) エンジンをベースに構築されています。

- 音声は原資料として永続保存
- AIは人生を書き換えない。候補を提示し、本人が確認する
- 紙の本は KDP（Amazon POD）＋ 著者用コピーによる自家販売 の二重経路
